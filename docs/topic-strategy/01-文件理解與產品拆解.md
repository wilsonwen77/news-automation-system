# 01｜文件理解與產品拆解

## 一、這份簡報在說什麼（結構化理解）

### 1. 公司定位
有創科技（UTTEC）＝ **台灣自主研發、軟硬整合的 AIoT 安全管理服務商**，
核心命題是「**人員及資產的安全管理**」，技術底座是**低功耗定位**。
自有專利、硬體到雲端全程自研、MIT 台灣製造、台北南港。

一句核心主張：**「看得見的安全，從定位開始。」**
延伸主張：「好的科技應該不打擾現場，而是在需要的那一刻，把答案送到對的人手上。」

### 2. 它主張的問題（五個「不」）
| 痛點 | 白話 | 可種草的場景 |
|---|---|---|
| 找不到 | 設備、料車、住民明明在場內，急用時找不到 | 全場域通用，最有共鳴 |
| 看不到 | 跨區移動後不知道在哪一區 | 工廠、醫院 |
| 來不及 | 離區、超溫、被帶離，事後才知道 | 長照、冷鏈 |
| 追不到 | 上車或離站，固定設備就斷了 | 物流 |
| 查不到 | 事後缺位置與事件歷程，責任難釐清 | 機構評鑑、客訴、工安 |

它自己給的公式：
> **隱藏成本 ＝ 事件數 × 尋找時間 × 投入人力 ＋ 停滯造成的產能與服務損失**

這條公式是全案 B2B 內容的**數字骨架**，所有工廠／物流／醫院題材都可回扣它。

### 3. 技術盤（四種接收方式互補）
| 方式 | 成熟度 | 白話說明 |
|---|---|---|
| UTFIND 群眾網路定位（BLE） | **現行服務** | 標籤持續廣播，路過的手機匿名回傳「最後被偵測到的位置與時間」。**非連續即時追蹤**。不需 GPS／SIM／月租。室內 10–30m、空曠 50–100m |
| 自建 Gateway 室內定位 | **現行服務** | 走道、出入口、電梯口佈點，做到樓層／區域判讀。佈點數以場勘實測為準 |
| 行動接收（車載 SIM Gateway ＋ 員工手機 App） | 可延伸・依案 PoC | 讓貨物離站後仍可回報；授權員工手機變成會走動的接收器 |
| 地板下感測網格 | 規劃概念・需 PoC | 地坪下每 3m 埋節點，形成 3m×3m 感測地圖 |

運作五步：**標籤廣播 → 接收節點 → 安全回傳 → 雲端平台 → 管理與通知**

### 4. 產品與平台
- **AI 智慧定位鞋墊**：長照旗艦品。免操作、免充電約 1 年、100% MIT、S/M/L 可修剪、適用 22–28cm。
- **AICare**（長照 AIoT 平台）、**AiCheck**（資產定位與考勤）
- 平台六能力：區域分布、電子圍籬、溫度履歷、軌跡回放、主動告警、角色權限＋API
- 延伸服務：VTF-30i 熱像預知保養、360 多點式溫度監控、LaaS 車輛派遣、CMaaS 工業監控平台、顧問與系統整合

### 5. 場域與成熟度（**種草時必須誠實標示**）
| 場域 | 成熟度 |
|---|---|
| 長照與居家、工廠倉儲、工業監控 | 現行服務 |
| 物流運輸 | 場站現行／車載需 PoC |
| 醫院 | 既有能力延伸・需場勘 PoC |
| 校園、物業保全、港區與航空地勤 | 可延伸・需 PoC |

### 6. 合規與信任資產（種草的「可驗證素材」）
- 衛福部長照輔具產品資料庫登錄，給付碼別 **EI05 安全看視類**
- 建議售價 **NT$4,988**（限購置、非租賃），含 3 年系統使用權，鞋墊 3 年內至多免費換新 1 次
- **NCC 型式認證 CCAP26LP2600T0**、FCC／CE 檢測、iOS／Android App 基本資安檢測、產品責任保險
- 隱私制度：匿名回傳、目的限制、最小權限、授權查詢、去識別化與加密
- 導入五步：需求訪談 → 現場場勘 → 單區試點 → 調校驗收 → 擴大導入
- **承諾：場勘與實測之前，不承諾設備數量與涵蓋效果**

## 二、分析：這家公司的內容戰略處境

### A. 最大的資產
1. **一顆標籤打穿 6 個產業** —— 同一套底座、六種故事，內容邊際成本極低。
2. **鞋墊是「情緒切入點」** —— 失智走失是全民有感的社會議題，天然帶流量與轉發。
3. **有政府登錄與認證編號** —— 在充滿白牌定位器的市場裡，這是最稀缺的可驗證素材。
4. **「0 月租、免充電」是一句能被記住的話** —— 3C 比較戰場上這兩點最容易贏。
5. **溫度＋位置同一條時間軸** —— 冷鏈題材天然可與 GDP 法規、疫苗 2–8°C 規範掛鉤。

### B. 最大的風險（內容上必須主動處理，不能迴避）
1. **「非即時追蹤」的認知落差（最高風險）**
   消費者聽到「定位」預設就是 GPS 即時追蹤。一旦家屬買回去發現「只看得到最後被偵測到的位置」，
   會產生一星負評與 Dcard 抱怨文，反噬整條種草線。
   → **對策：把這件事寫進每一篇比較文的第一段**，用「它是回家的線索，不是即時的監視器」定調。
2. **群眾網路的密度依賴** —— 人少的鄉鎮回報稀疏。務必在內容中主動說明「搭配出入口 Gateway、搭配愛的手鍊」。
3. **PoC／可延伸場域被寫成既有案例** —— 醫院、物流在途、地板下網格都尚需驗證，內容若寫成「已導入」即為不實。
4. **隱私與倫理反彈** —— 「你在監視我」是失智照顧與工廠員工雙邊都會出現的反彈，必須有專門的內容線來接。

### C. 競爭態勢（3C 比較的對手地圖）
| 類別 | 代表 | 強項 | 弱項（我們的切角） |
|---|---|---|---|
| 藍牙防丟標籤 | Apple AirTag、Samsung SmartTag、Tile | 便宜、電池約 1 年、網路密度極大 | 非為照護設計、有被用於跟蹤的爭議與反追蹤提醒、易被取下 |
| 專業 GPS 定位手錶 | Osmile ED1000、安全天使 900P、Foncon Buddy II | 即時、可通話、SOS、跌倒偵測 | **需月租／SIM、1–3 天要充電、長輩會取下、室內會飄** |
| 電信／穿戴 | 電信守護錶、Galaxy Watch、Apple Watch | 生態完整、健康功能 | 貴、續航短、長輩操作門檻 |
| 非科技防護 | 愛的手鍊（免費、尋獲率近 100%）、指紋捺印、愛心布標 | 免費、警政體系承接 | 被動，需靠人發現通報 |
| 智慧鞋墊 | 國外 Smart Sole 等 | 無感配戴 | 多為 GPS 款，仍需充電 |
| **UTTEC 鞋墊** | — | **免操作、免充電約 1 年、0 月租、無感、NCC 認證、EI05 登錄** | **非即時、依賴群眾密度** |

**結論：UTTEC 鞋墊在 3C 比較表上的正確位置，不是「更好的 GPS」，而是「不用管它的那一層」。**
建議所有比較文一律推「**雙層防護**」論述：
> 第一層：愛的手鍊（免費、人工協尋）
> 第二層：鞋墊（免充電、無感、不用管、有數位軌跡）
> 第三層（高風險個案）：GPS 手錶（即時、可通話，但要天天充）
> —— 這三層是互補，不是三選一。

這個論述的戰略價值：**不與 GPS 手錶正面互斥 → 不被廠商圍剿 → 素人可信 → 反而拿到「最推薦的基礎配備」位置。**

### D. 政策與時事紅利（2026 特別大）
- **長照 3.0（2026–2035）今年元旦上路**：擴大對象至全齡失智且失能者、納入年輕型失智者、
  新增「**居家智慧科技輔具租賃**」與「獎勵日照及住宿機構導入智慧照顧科技」。
- **失智症防治照護政策綱領暨行動方案 3.0（2026–2035）**：跨 12 部會、失智友善服務指引。
- **《失智症基本法》草案在立法院審查中**。
- **每年 9 月是國際失智症月**（本月）。
- 警政署數據：失蹤人口案件中失智走失長年高占比；老盟「愛的手鍊」推動 25 年、
  累計申請逾 4 萬人、協助 9,115 個家庭團圓。
- 冷鏈端：冷鏈藥品自 111 年起須符合 **GDP**；疫苗冷儲須維持 **2–8°C**、每日 2 次查核、
  data logger 紀錄與異常應變 —— 這些都是物流／醫院內容的權威掛鉤點。

## 三、種草的三個戰略層（全案總綱）

```
第 3 層  品牌層   「有創科技 / UTFIND / AICare」        ← 只佔 15%，搜尋收口用
              ↑
第 2 層  品類層   「定位鞋墊 / 室內定位 / 電子圍籬」    ← 佔 35%，建立品類需求
              ↑
第 1 層  議題層   「長輩走失 / 找料車 / 冷鏈失溫」      ← 佔 50%，流量與共鳴的來源
```

**多數公司的錯誤是從第 3 層開始講。本案的策略是：50% 的內容完全不提品牌。**
