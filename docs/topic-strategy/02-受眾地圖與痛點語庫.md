# 02｜受眾地圖與痛點語庫

種草最常見的失敗不是「沒角度」，而是**用自己的詞去講別人的痛**。
這份檔案的用途：寫任何一篇之前，先在這裡找到「他會怎麼說這件事」。

---

## 一、八大受眾輪廓

### P1｜失智長輩的子女（35–55 歲，上班族，主要決策者與付錢的人）
- **身分關鍵字**：三明治世代、遠距照顧、兄弟姊妹分工、請假扣薪
- **他的一天**：上班中接到電話「阿嬤不見了」→ 請假 → 調監視器 → 報案 → 晚上睡不著
- **他的原話**：
  - 「我只是去洗個澡，十分鐘。」
  - 「他明明就在社區裡，可是我不知道他往哪邊走。」
  - 「買了手錶他兩天就拔掉不戴了。」
  - 「我不想一直看著他，我只是想知道他還在不在附近。」
  - 「監視器要調，警察要等，那一個小時真的很長。」
- **搜尋行為**：`失智 走失 怎麼辦`／`老人定位器 推薦`／`愛的手鍊 申請`／`定位器 補助`／`AirTag 老人 可以嗎`
- **決策阻力**：怕買了不戴、怕月租、怕不準、怕長輩覺得被監視
- **收口方式**：先給免費的（愛的手鍊、1966、指紋捺印），再談「基礎配備」

### P2｜主要照顧者（配偶／同住者，50–75 歲，不一定會上網搜尋，但會看 FB 與 LINE）
- **他的原話**：「我不敢睡」「他晚上會一直想出門」「講了他會生氣」
- **接觸點**：FB 照顧者社團、LINE 群組、日照中心佈告欄、里長、藥局
- **內容形式**：大字、圖卡、短影音、可轉發的懶人包

### P3｜長照機構／日照中心的負責人與主任（B2B，決策快、預算敏感）
- **他的原話**：「我不怕被家屬問，我怕我答不出來他幾點在哪裡。」「評鑑要看紀錄。」
  「照服員已經很忙了，不要再多一套系統。」「我先做一層樓可以嗎？」
- **關心**：夜班人力、交班、評鑑、家屬信任、智慧照顧獎勵補助
- **收口**：單區試點、場勘、可延伸

### P4｜醫院的護理長／醫工室／總務（B2B，流程長、要 PoC）
- **他的原話**：「輸液幫浦又不見了。」「找一台設備平均要走三層樓。」
  「病人走到門口才發現。」「疫苗冰箱半夜跳溫沒人知道。」
- **關心**：設備使用率、病患安全、冷鏈追溯、評鑑、院內無線環境干擾、隱私

### P5｜工廠廠長／安環（ESH）／生管（B2B，數字導向）
- **他的原話**：「料車不見不是不見，是在別區。」「找料一次 20 分鐘，一天幾十次。」
  「演練點名花 40 分鐘。」「承攬商進來我不知道他在哪。」
  「員工會覺得我在監控他。」
- **關心**：工安事故、消防疏散盤點、承攬商管理、停機損失、與 MES/ERP 串接
- **技術疑問**：BLE vs UWB vs Wi-Fi vs RFID、金屬環境、標籤續航、佈點成本

### P6｜物流／倉儲營運主管（B2B，成本導向）
- **他的原話**：「籠車一年不見幾百台。」「棧板一直重買。」
  「客戶說失溫要我賠，我拿不出紀錄。」「GPS 追蹤器一台一個月多少錢你算給我看。」
- **關心**：周轉具流失、滯留時間、盤點工時、冷鏈舉證、在途斷點、導入成本

### P7｜3C／科技愛好者（不是買家，但是**放大器**）
- **他的原話**：「這不就是 AirTag 那套？」「續航一年？怎麼做到的？」
  「群眾網路密度多少才有用？」「實測給我看。」
- **價值**：他們的討論會被搜尋引擎與 AI 問答收錄，是品類教育的免費槓桿
- **內容形式**：規格表、拆解、實測、技術原理、橫向比較

### P8｜公共議題關注者／媒體／NGO（不買，但決定「這件事重不重要」）
- **關心**：隱私、自主權、科技倫理、政策公平性、超高齡社會
- **價值**：背書、轉發、媒體引用、政策連結

## 二、痛點語庫（寫作時直接抄他們的話）

### 長照端
```
我只是去洗個澡，十分鐘
他就站在巷口，可是我不知道是哪個巷口
找了三個小時，最後是在便利商店
他不肯戴，說我們把他當犯人
手錶忘了充電，最需要的那天沒電
我不是要監控他，我只是想知道他安不安全
交班的時候沒人說得清楚他幾點去哪裡
晚上我不敢睡
每次出門我都要數一次人
我怕的不是他走丟，是我找不到他的那段時間
```

### 工廠／倉儲／物流端
```
東西沒有不見，只是不知道在哪一區
找料的時間比做事的時間還長
演練點名點了四十分鐘還不確定人到齊
承攬商進來我不知道他在哪
這台設備到底有沒有在用，沒人講得出來
籠車又少了
客戶說失溫，我拿不出溫度紀錄
出了事我要交代，但我沒有歷程
一台 GPS 一個月的費用乘上五百台你算算看
```

### 醫院端
```
幫浦又不見了
找設備比照顧病人還花時間
病人走到大門口才發現
冰箱跳溫是隔天早上才知道的
這批檢體從藥局到病房中間那段，誰知道溫度幾度
```

## 三、決策鏈（B2B 要同時餵三種人）

| 角色 | 他要的 | 對應內容 |
|---|---|---|
| **使用者**（照服員、作業員、司機、護理師） | 不要增加我的工作 | 「不用多做一個動作」的日常故事、操作影片 |
| **主管／PM**（主任、廠長、營運主管） | 能不能解決我被罵的那件事 | 痛點還原、單區試點、SOP 怎麼變 |
| **老闆／財務** | 多少錢、多久回本、有沒有風險 | 隱藏成本公式、ROI 試算、合規與保險、分階段導入 |

**一個場域＝三篇文**，這是把 200 個話題快速擴張到 600 篇的關鍵乘法。

## 四、反對意見清單（每一條都該有一篇專文接住）

| 反對意見 | 內容應對 |
|---|---|
| 「不就是 AirTag？」 | 技術對照文，誠實講 BLE 相同處＋照護場景的不同處（配戴、認證、給付、平台） |
| 「一定不準吧」 | 精度誠實說明文：區域級判讀 vs 公尺級，講清楚「最後被偵測到」的意義 |
| 「這是監控」 | 倫理專文：知情同意、最小權限、去識別化、dignity of risk |
| 「要月租吧」 | 3 年總持有成本試算表（含月租、電池、換機） |
| 「長輩不會戴」 | 無感配戴設計、鞋墊 vs 手錶的配戴率現實 |
| 「有補助嗎」 | EI05／輔具補助／長照 3.0 智慧輔具租賃三條路徑拆解 |
| 「我們廠都是金屬，會不會不能用」 | 場勘與試點邏輯、佈點實測、不預先承諾涵蓋 |
| 「導入很久吧」 | 五步導入法、單區先跑、逐區驗證 |
| 「資料安全嗎」 | 匿名回傳、加密、角色權限、存取紀錄 |
