# 08｜品牌滲透與擴散戰略模型

> 這份是全案的「戰略邏輯層」。
> 前面 01–07 回答「內容做什麼」，這份回答「為什麼這樣做會讓品牌長出來」。

---

## 一、先分清楚三個常被混用的詞

| 詞 | 定義 | 衡量方式 | UTTEC 目前的狀態 |
|---|---|---|---|
| **品牌滲透（Penetration）** | 在特定人群中，有多少人「知道並考慮過」你 | 提及率、被納入比較的次數 | 幾乎為 0（B2C 端）／區域性（B2B 端） |
| **品牌擴散（Diffusion）** | 資訊沿著人際與體系網路自行傳遞的能力 | 自然轉發、被第三方引用、被專業人員轉介 | 未啟動 |
| **品牌行銷（Marketing）** | 主動投放與溝通 | 觸及、CPC、CPA | 未啟動 |

**順序極重要**：多數 B2B 硬體公司的錯誤是直接做第 3 項（投廣告）。
本案的主張是 **滲透 → 擴散 → 行銷**：
先讓內容成為「被搜尋到的可信物」，再讓體系與人際幫你傳，最後才用付費放大已被驗證的內容。

---

## 二、核心洞察：UTTEC 賣的不是定位，是「那段空白時間」

所有場域的痛點都可以化約成同一個句型：

```
事情發生了  →  ??? （空白）  →  我才知道
```

| 場域 | 空白是什麼 | 空白的代價 |
|---|---|---|
| 長照 | 從長輩離開到家屬發現的 30 分鐘 | 生命風險、家庭崩潰 |
| 機構 | 從離區到值班人員知道的時間 | 責任、評鑑、信任 |
| 工廠 | 從「要用」到「找到」的 20 分鐘 × 一天數十次 | 工時、停機 |
| 物流 | 從失溫到客戶拒收 | 賠償、客戶流失 |
| 醫院 | 從冰箱跳溫到隔天早上 | 疫苗報廢、稽核缺失 |

**戰略命名建議：把 UTTEC 的品牌敘事統一成「消除空白」。**
這個敘事的好處是——B2C 與 B2B 共用同一句話，內容資產可以互相加乘，不需要兩套品牌語言。

## 三、品牌滲透的四個槓桿（依 ROI 排序）

### 槓桿 1｜政策與資格槓桿（最高 ROI，已經握在手上卻沒用）
- 衛福部長照輔具資料庫 **EI05** 登錄、NCC 型式認證編號、FCC/CE、App 資安檢測、產品責任保險
- 白牌定位器市場最缺的就是「可被查證的身分」
- **打法**：把「怎麼自己查證」做成內容（教讀者去查政府資料庫），而不是自己喊認證
- **原理**：讓讀者自己驗證＝把說服權交給讀者＝信任成本最低

### 槓桿 2｜體系轉介槓桿（B2C 最被低估的通路）
長照體系中，家屬的購買決策高度依賴「專業人員說的話」：
```
1966 → 照管專員 → 照顧計畫 → 特約輔具單位 → 評估/配適
        ↑                        ↑
   內容可影響的節點        真正成交發生的地方
```
- **關鍵認知**：B2C 的內容不是直接賣給家屬，而是要讓**照管專員、輔具評估人員、社工、日照主任**認得這個產品
- **打法**：專業人員導向的內容（專業版 FAQ、評估要點、配適教學、案例整理），走 LinkedIn／產業媒體／研討會／輔具中心，而不是 IG
- 這是一條「B2B2C」的路線，成本遠低於直接打廣告給家屬

### 槓桿 3｜比較與技術權威槓桿（3C 戰場）
- 這個品類的消費者**一定會比較**，問題只是「有沒有你」
- 進不了比較表＝不存在
- **打法**：自己做出品類裡最誠實、最完整的比較內容（含免費方案、含競品優點、含自己做不到的事）
- **原理**：在低信任品類裡，**主動承認缺點的品牌會被當成唯一可信的資訊源**

### 槓桿 4｜情緒與議題槓桿（擴散的引擎）
- 走失、照顧者疲憊、隱私倫理 —— 這些會被自然轉發，定位規格不會
- **打法**：50% 內容完全不提品牌，只講議題
- **原理**：擴散靠的是「值得轉給別人的東西」，不是「值得買的東西」

## 四、雙飛輪模型（B2C 與 B2B 如何互相供養）

```
        ┌──────────── B2C 飛輪（情緒／擴散快） ────────────┐
        │                                                 │
   走失議題內容 → 家屬搜尋 → 比較內容 → LINE 詢問 → 補助路徑
        ↑                                                 ↓
   媒體引用 ← 使用者見證 ← 成交與配適 ←────────────────────┘
        │
        │  【橋樑】同一套定位底座 ＋ 同一句「消除空白」
        │  【人的橋樑】一個廠長也可能是失智長輩的兒子
        ↓
        ┌──────────── B2B 飛輪（信任／週期長） ────────────┐
        │                                                 │
   場域痛點內容 → 專業人員／主管搜尋 → 方法論內容 → 場勘預約
        ↑                                                 ↓
   產業媒體/展會 ← 可公開的流程改善 ← 單區試點 ←───────────┘
```

**橋樑的操作方式（這是本案最有價值的結構設計）：**
1. **信任遷移**：B2C 的「政府登錄＋誠實比較」形象，會降低 B2B 決策者的風險感知
2. **人員重疊**：工廠廠長、醫院總務、物流主管——他們同時是「有長輩的中年人」
3. **內容重用**：一篇「電子圍籬怎麼設才不會誤報」同時服務家屬與廠務
4. **案例互證**：機構導入案例可以回頭成為 B2C 的信任素材（「連機構都在用」）

## 五、心智階梯（讀者從不認識到成交要爬的五階）

| 階 | 讀者心理狀態 | 對應內容 | 此階的唯一任務 |
|---|---|---|---|
| **S1 無意識** | 「這不會發生在我家」 | 議題文、故事、數據（L0） | 讓他**記得有這件事** |
| **S2 問題意識** | 「我家好像也開始了」 | 走失 SOP、免費資源、補助流程（L0–L1） | 讓他**收藏／加入 LINE** |
| **S3 方案探索** | 「有什麼東西可以用」 | 品類教育、四大類裝置比較（L1） | 讓他**理解品類分類** |
| **S4 方案比較** | 「哪一個適合我家」 | 橫向比較、TCO 試算、實測（L2） | 讓他**把我們放進比較表** |
| **S5 決策與取得** | 「怎麼買、有沒有補助」 | 補助路徑、購買/申請教學、見證（L2–L3） | 讓他**打 1966／詢問客服** |

> **最常見的錯誤是拿 S5 的內容去打 S1 的人**（對還沒問題意識的人講規格）。
> 客服系統的分流邏輯，就是判斷「這個人現在在第幾階」，見 `09`。

## 六、擴散係數：哪些內容會自己長腳

可轉發性由高到低：
```
1. 免費資源整理（愛的手鍊、1966 流程）      ← 轉給家人、轉進社團
2. 情緒故事（我家的那一天）                  ← 引發同類留言
3. 反直覺的數據（走失佔失蹤通報的比例）      ← 媒體與意見領袖引用
4. 唱反調（我不建議你買定位器）              ← 帶動辯論
5. 翻車實測（地下室全軍覆沒）                ← 3C 圈轉發
6. 工具（決策表、SOP 卡、檢核表）            ← 被存檔、被專業人員轉發
--- 以下幾乎不會被轉 ---
7. 產品規格、公司新聞、展會消息
```
**資源配置原則：把 70% 的製作預算放在 1–6，30% 放在 7。**

## 七、三年戰略節奏（滲透 → 擴散 → 行銷）

| 期 | 目標 | 主要動作 | 成功長什麼樣 |
|---|---|---|---|
| **第 0–6 月：可信度地基** | 進入搜尋結果、建立內容資產 | 首波 30 條、比較內容、工具化資產、專業人員內容 | 核心關鍵字進前 10；照管專員/輔具人員聽過 |
| **第 7–18 月：體系與擴散** | 進入專業人員的轉介名單、B2B 單區試點 | 研討會/產業媒體、機構試點、使用者見證、展會 | 出現「別人主動推薦你」的紀錄 |
| **第 19–36 月：放大與品類定義** | 成為品類的預設答案之一 | 付費放大已驗證內容、通路拓展、跨境評估 | 品牌字搜尋量成長；比較文一定有你 |

## 八、這個戰略的三個死穴（先寫下來，才能防）

1. **內容做了但沒有承接**：流量進來卻沒有 LINE／表單／客服分流 → 見 `09`、`10`
2. **誠實策略被業務端破壞**：內容說「非即時」，業務為了成交說「可以即時看」→ 必須做內外一致的話術訓練
3. **B2B 期待被內容拉太高**：文章寫得像已經全場導入，實際需要場勘 PoC → 成熟度標示必須內外統一

> 這三點不是內容問題，是**組織一致性**問題。研究案的結論若不進到客服與業務的 SOP，內容做得再好也會漏光。
