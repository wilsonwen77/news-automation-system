# 06｜合規紅線與風險控管（發文前必讀）

> 這份檔案不是法務意見，是內容團隊的自律清單。
> 涉及法規解釋與個案判斷時，請先送法務／外部律師確認。

## 一、最高優先：三句不可以說的話

| ❌ 不可以寫 | ✅ 改成 |
|---|---|
| 「即時追蹤長輩位置」 | 「回報最後一次被偵測到的位置與時間」 |
| 「保證不會走失／一定找得到」 | 「縮短從發現到找到的時間，是輔助工具」 |
| 「醫院／物流已導入，成效 XX%」（尚需 PoC 的場域） | 「既有能力延伸，導入需場勘與 PoC 驗證」 |

## 二、產品宣稱

- **不得宣稱醫療效能**：不可寫「預防失智」「治療」「改善認知」。定位鞋墊是安全看視類輔具，不是醫療器材療效宣稱。
- **不得誇大涵蓋範圍**：偵測距離（室內約 10–30m、空曠約 50–100m）須標明是條件值，並加「依環境而異」。
- **續航須加註**：「約 1 年」必須帶但書 ——「依回報頻率與環境溫度而異，以正式量產規格為準」。
- **成熟度必須標示**：現行服務／可延伸／需 PoC 三級，不可混用。
- **場勘前不承諾**：沿用官方承諾語「場勘與實測之前，不承諾設備數量與涵蓋效果」。

## 三、政策、補助與價格

- 補助資格、金額一律加註：**「以居住地縣市長照主管機關公告為準，須經特約輔具單位辦理」**。
- 引用衛福部輔具資料庫、給付碼別、建議售價時，**標註查詢日期與來源連結**。
- 不得暗示「政府推薦」「政府指定」——資料庫為產品查詢平台，不涉商品推薦或特約。
- 政策每年會調整，所有政策文需設**半年複查排程**。

## 四、比較型內容（線 B 的主要風險區）

1. 競品規格一律引用**官方公開頁面**，截圖存證並標註日期。
2. 只比**可驗證**項目（價格、續航、月租、認證編號、功能有無）。
3. 實測須說明**條件**（時間、地點、裝置版本、韌體），並承認樣本限制。
4. 不得使用貶損性形容、不得暗示競品有安全疑慮、不得比較未經授權的商標視覺。
5. 不得捏造「XX 款壞掉了」等未實際發生的情節。
6. 涉及 AirTag 等他牌被用於跟蹤的討論，只引述公開報導與官方反制功能說明，不指控特定廠商。

## 五、素人種草的界線（最容易出事的地方）

| 可以 | 不可以 |
|---|---|
| 真實使用者自願分享、經同意刊出 | 公司帳號假扮成素人 |
| 與創作者合作並**標示合作關係** | 有對價卻不揭露 |
| 提供樣品請對方誠實評測（含缺點） | 要求對方隱藏缺點或指定好評 |
| 員工以真實身分具名發表專業觀點 | 員工假扮消費者留言 |
| 整理真實留言做成 FAQ | 編造用戶留言或評分 |

**準則：付了錢、給了東西、有僱傭關係 —— 三者任一成立就要揭露。**
（可用 `#合作`、`#業配`、`#公司提供產品實測`、`#我是 OO 公司員工`）

## 六、個資與隱私

- 故事型內容：當事人（或法定代理人）**書面同意**；去識別化姓名、門牌、可辨識背景。
- App／後台截圖：住民姓名、床號、員工工號、車牌、地圖精確座標一律打碼。
- B2B 案例：不寫客戶名稱與可辨識場域特徵，除非取得書面授權。
- 長照場景務必附上：「**配戴前應取得本人或法定代理人同意；定位為輔助工具，不取代照顧者看視與必要安全措施。**」
- 不得將定位資料用於文章中未經授權的二次分析。

## 七、員工／人員定位的敏感表述

- 一律強調：**去識別化群體統計、最小權限、目的限制**。
- 不得暗示可用於「抓怠工」「考核個人」——這是產業內容最容易引發反彈的雷。
- 涉及勞工權益的討論，用開放提問而非斷言。

## 八、平台規則

| 平台 | 注意 |
|---|---|
| Dcard | 禁止未揭露商業行為、禁止多帳號洗串 |
| PTT | 各板規差異大，商業內容多數需先詢問板主 |
| Mobile01 | 廠商身分需表明，違者水桶 |
| FB 社團 | 多數禁廣告，需與管理員事先溝通 |
| IG／Threads | 合作內容需開啟品牌置入標示 |
| YouTube | 需勾選「含付費宣傳內容」 |

## 九、危機情境與應對

| 情境 | 預先準備 |
|---|---|
| 有人實測後說「根本查不到位置」 | 準備「群眾密度／回報機制」說明稿 ＋ 主動聯繫協助排查，公開回覆不刪文 |
| 被指「帶風向、假素人」 | 揭露紀錄可回溯：合作名單、揭露標籤、素材同意書 |
| 走失憾事發生且當事人使用本產品 | 不行銷、不辯解、不比較；以家屬意願為優先，由公司具名說明而非 KOC |
| 競品公開反駁比較文 | 以規格出處與查詢日期回應，錯了就改並公告修正 |
| 政策數字過期被指正 | 24 小時內更新並標註「已於 X 月 X 日更新」 |

□ 截圖打碼了嗎？
□ 故事當事人同意了嗎？
