## 話題庫的擴張公式（200 → 1,000+）

每一條話題都可以再乘以以下維度，形成長尾：

1. **格式乘法**：長文 / 圖卡 / 60 秒短影音 / 表格 / Q&A / 懶人包 / 電子書
2. **角色乘法**（B2B）：使用者版 × 主管版 × 老闆版
3. **地區乘法**：台北 / 台中 / 高雄 / 各縣市補助差異（SEO 長尾金礦）
4. **時序乘法**：預防前 / 事發當下 / 事後追溯
5. **程度乘法**：輕度 / 中度 / 重度；小廠 / 中廠 / 大廠
6. **情緒乘法**：同一件事寫成「教學版」與「我家的故事版」
