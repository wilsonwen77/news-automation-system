> 這是**第二條研究線**：與線 A（議題樹）邏輯完全不同。

## 國際技術錨點：本表引用的事實基礎

依指示，每條議題都要帶到國際等級的定位技術。以下是查證後可安全引用的錨點：

### 1. Bluetooth Channel Sounding（Bluetooth Core 6.0）
- Bluetooth SIG 於 **2024-09-03** 隨 Core 6.0 發布
- 以**相位測距 PBR** 為主、**往返時間 RTT** 為輔（RTT 同時用於防中繼攻擊）
- SIG 表示可達**公分級**精度
- 使用 80 個 1MHz 頻道，扣除廣播頻道後 **72 個可用於測距**（對比 BLE 的 40 個 2MHz 頻道）
- 最多支援 **4 條天線路徑**
- **Google Pixel 10** 已支援；**Apple 於 iOS 27** 以 Core Bluetooth／Nearby Interaction 開放，
  配件須支援 **Bluetooth 6.3 與 inline PCT**
- ⚠️ **誠實補充**：IEEE Access（2025）的商用硬體實測指出，
  **單天線設定在高精度定位上仍不夠穩健，離群值必須處理**。引用時不要只講公分級。

### 2. UWB / FiRa（IEEE 802.15.4z、發展中的 802.15.4ab）
- 脈衝無線電，頻寬約 **500MHz–1.3GHz**，運作於 **6.5–8.0GHz**
- 皮秒級時戳，**抗多路徑能力強**，NLOS 下仍可維持高精度
- 代價是功耗：**Tx 約 45–75mA**，相較 Bluetooth 6.0 CS 的 **4.0–6.5mA**
- 因此 **CR2032 鈕扣電池帶不動 UWB**，需外加超級電容，提高 BOM 與體積

### 3. 群眾網路：Apple Find My × Google Find Hub
- 兩大體系並存；Google 的**未知追蹤器警示**同時相容 Find Hub 標籤、耳機與 **Apple AirTag**

### 4. IETF DULT 工作組（Detecting Unwanted Location Trackers）
- Apple 與 Google 共同推動的標準化工作
- 標準化三個子系統：**群眾網路、非預期追蹤偵測、警示與協助非擁有者尋找**
- 這是談「定位倫理」時最有力的國際依據

## 使用方式（四條紀律）

1. **每條議題在內文帶到欄位 E 的 2–3 個國際錨點**，作為可信度基礎。
2. **再依欄位 F「間接帶入點」把話題收回自家服務**——不要一開場就講產品。
3. **層級配比與線 A 一致**：L0 不提品類、L1 提品類不提品牌、L2 可並列比較。
4. **引用國際規格務必標註來源與查詢日期**——標準會改版，Bluetooth 6.0 才發布兩年就已有 6.3。

## 已知限制

xlsx 的統計頁使用 COUNTIF／SUM 公式而非寫死數字。
本容器的 LibreOffice 三次重算均逾時，**公式快取值為空**——以 Excel 或 Google 試算表開啟會自動計算。
本文件中所有數字均已另以 Python 獨立核對。
