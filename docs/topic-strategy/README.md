## 一句話結論（給趕時間的人）

UTTEC 真正的種草切角**不是「我們是定位公司」**，而是三個誰都聽得懂的生活句子：

1. **「找不到人的那 30 分鐘。」**（長照／醫院／機構）
2. **「找不到東西的那 30 分鐘 × 一年幾百次。」**（工廠／倉儲／物流）
3. **「免充電、免月租、免操作 —— 但它不是即時追蹤。」**（3C 比較的誠實護城河）

第 3 點是全案的**成敗關鍵**：AI 智慧定位鞋墊走的是 BLE 群眾網路，
回報的是「最後一次被偵測到的位置與時間」，不是連續即時 GPS 追蹤。
所有種草內容都必須先承認這件事，再把它轉成優勢（不用充電、不用月租、長輩無感）。
一旦在比較文裡含糊帶過，被實測打臉的反噬會比沒做還嚴重。詳見 `01` 與 `06`。
