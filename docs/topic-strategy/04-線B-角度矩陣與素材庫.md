### 五條鐵律
1. **先講糗事，再講好處。** 沒有缺點的分享一定像業配。
2. **一篇只講一件事。** 講三個優點＝零個優點。
3. **給得出時間、金額、次數。** 「找了 3 小時」「一年 4,988」「一天找 6 次料」。
4. **主動承認限制。** 「它不是即時追蹤」這句話要出現在前三段。
5. **收口要留白。** 不放購買連結，放「查詢方式」「我問過的問題清單」。

## 二、3C 比較專章（線 B 的主力火力）

### 2.1 比較維度標準表（所有比較文共用，保證口徑一致）

| 維度 | 說明 | 為什麼讀者在意 |
|---|---|---|
| 定位方式 | GPS／AGPS／BLE／Wi-Fi／基地台 | 決定「準不準、室內行不行」 |
| 回報型態 | **即時連續 vs 最後偵測點** | 全篇最關鍵、最常被含糊帶過 |
| 續航 | 天 / 月 / 年；是否可換電池 | 忘記充電＝當天失效 |
| 月租 | SIM／平台費／有無綁約 | 三年總花費的決定因素 |
| 配戴形式 | 手錶／項鍊／吊牌／鞋墊／縫入衣物 | 決定「他會不會拔掉」 |
| 配戴接受度 | 有無感、會不會被當成監視 | 真實失敗率的來源 |
| 室內表現 | 地下室、賣場、電梯 | 走失最常發生的地方 |
| 覆蓋依賴 | 衛星／基地台／群眾密度／自建閘道 | 鄉下 vs 市區差很大 |
| 功能 | 圍籬／軌跡／SOS／通話／跌倒／溫度 | 對應不同失智程度 |
| 認證 | NCC／FCC／CE／App 資安檢測 | 白牌市場的分辨點 |
| 補助資格 | 是否登錄輔具資料庫／給付碼別 | 直接影響自費金額 |
| 售後 | 保固、換新、資料歸屬 | 長期使用的真成本 |

### 2.2 五種可直接套用的比較文模板

1. **「三種根本不同類」型**（最推薦的開場）
   > 很多人把 AirTag、GPS 手錶、定位鞋墊放在一起比，但它們回答的是三個不同問題：
   > 「東西掉了嗎」「他現在在哪」「他最後出現在哪」。搞錯問題，買什麼都不對。

2. **「三年總成本」型**：把裝置價 ÷ 36 個月，加上月租、電池、換機、補助差額，做成一張表。

3. **「翻車實測」型**：同一天、同一條路線、同時戴上 N 款，把回報紀錄原樣貼出來。

4. **「分級推薦」型**：輕度／中度／重度 × 同住／獨居 × 市區／鄉下 → 給不同答案，不推同一款。

5. **「把免費選項放進比較表」型**：愛的手鍊、指紋捺印、布標一起列。
   願意推薦免費方案的比較文，可信度是其他文的數倍。

### 2.3 比較文的三條紅線（違反就會反噬）
- 不得暗示自家為「即時追蹤」。統一用語：**「回報最後一次被偵測到的位置與時間」**。
- 競品規格一律引用官方頁面並標註查詢日期，不憑印象寫、不寫「聽說」。
- 不得貶抑競品安全性或人身攻擊；只比可驗證的規格與實測。
