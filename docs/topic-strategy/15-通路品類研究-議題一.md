# 15｜通路品類研究・議題一
## 「長照輔具通路這門生意，2026 年變了什麼？」

> 對應話題編號：A11-01／A11-03／A11-04／A11-08（合併深化）
> 研究日期：2026-09-19　所有制度事實均附來源，政策以官方公告為準

---

## 一、為什麼這是通路方向的第一個議題

因為 **2026/7/1 之後，「輔具通路」這個詞的定義被改掉了。**

在此之前，通路 = 賣東西的店。
在此之後，通路 = **要有清消場地、回收物流、營運計畫書、受審查的服務業者**。

這不是一個修辭。它是一整套**有坪數、有動線、有證照**的實體門檻。
門檻一旦拉高，通路家數就會減少；通路家數減少，**願意進場的人議價力就上升**。

對一個要找經銷商的廠商來說，這是全案最該先看懂的一件事：
**你不是在找「願意賣你東西的店」，你是在找「過得了這關的店」。**

---

## 二、通路的真實結構：三種角色，不要混為一談

台灣長照輔具的流通，有三個**法律地位完全不同**的角色：

```
① 產品登錄廠商（UTTEC 在這一層）
      ↓ 產品須通過審議，納入給付清單
② 特約單位（藥局／醫療器材行／輔具商）
      ↓ 與縣市政府簽約，執行代償墊付
③ 甲類輔具評估人員（醫療／治療專業）
      ↓ 開立評估報告，指定「類別與碼別」，不指定品牌
```

**關鍵理解：**
- ①和②**不是同一件事**。產品進了給付清單，不代表任何一家店會進你的貨。
- ③**不能替你賣**。他開的報告寫的是碼別，不是品牌。
- **真正決定家屬手上拿到哪一支產品的，是②。** 而②的動機是：好不好賣、好不好管、會不會被客訴、請款順不順。

> 這推翻了一個常見的直覺：「只要進了政府清單就會賣」。
> 進清單只是拿到入場券，**通路才是球場**。

## 三、成為特約單位的實際門檻（有數字的那種）

彙整多個縣市的公告（基隆、花蓮、新竹市、彰化、台中、台東），門檻高度一致：

### 3.1 基本資格

| 項目 | 要求 |
|---|---|
| 法人資格 | 依商業登記法辦理商業登記，**或**依藥事法第 27 條取得**藥商許可執照** |
| 營業項目 | 須含醫療器材製造／批發／零售、醫療耗材零售、藥品及醫療用品零售等 |
| **實體店面** | **必須有**。且須具備售後維修、展售空間、教導正確使用的能力 |
| 人員 | 服務人員須持**輔具供應人員資格訓練課程結業證明** |
| 信用 | 非政府採購法第 103 條拒絕往來廠商；**近 2 年無民眾抱怨投訴** |
| 在地性 | 部分縣市（如花蓮）明訂**以在地廠商為主** |

### 3.2 做「租賃」還要再加一層（這是 2026 的新門檻）

| 項目 | 要求 |
|---|---|
| **營運計畫書** | 須提送並經縣市審查通過，**必要時實地勘察** |
| **門市空間** | 台中要求租賃服務門市室內空間**至少 6 坪**，且須能讓個案試用與訓練 |
| **清消空間** | 清潔消毒**每一工作流程的空間至少 5 坪**（約 16.5 ㎡）、**走道至少 2 公尺** |
| **動線** | 使用過的輔具與消毒過的輔具**分開置放、不同出入口** |
| 清消標準 | 須符合衛福部《長照輔具清潔及消毒指引手冊》 |
| 委外 | 清消可委外，但須檢附委外單位名稱與簽約佐證 |
| 訂價 | 租賃**訂價須公開揭示**（網路或海報），且與營運計畫書一致；**異動須報備查** |

> **這一段是本議題的核心發現。**
> 清消場地的坪數要求，讓**多數社區藥局實質上做不了租賃**——
> 一間藥局不會為了輔具去騰出兩個各 5 坪、動線分離的清消空間。
>
> 結果是：**購置特約家數 >> 租賃特約家數**。
> 而智慧科技輔具的五大類（EI01–EI05）**全部是「限租賃」**。

### 3.3 代償墊付：通路的現金流現實

- 自 **2024/1/1 全面實施**。民眾只付部分負擔，補助款由**特約單位先墊、再向地方政府請款**。
- **特約單位不得以任何理由拒絕提供代償墊付服務。**
- 核銷須備：領款收據、請款清冊、支出憑證黏存單、核定通知書影本、給付證明、輔具照片，以及
  **保固書影本**（須載明規格／型號／**序號**／保固年限起迄／供應商行號與統編／負責人／保固服務電話／醫療器材查驗登記字號）

> **通路端的真實痛點在這裡**：他先出錢、後請款，中間是現金流缺口；
> 而且核銷文件只要缺一項就退件。
> **一個能把核銷文件包做到位的廠商，對通路的價值遠大於多給兩個百分點的折讓。**

## 四、租賃新制對通路的衝擊（2026 最大的變化）

| | 舊制（長照 2.0） | 新制（2026/7/1 起） |
|---|---|---|
| 模式 | 以購置買斷為主 | 新增**智慧科技輔具全租賃**軌道 |
| 額度 | 每 3 年 4 萬 | 每 3 年 **6 萬**（含居家無障礙上限 2 萬） |
| 選擇 | — | **二擇一**，選了一組，另一組要滿 3 年才能用 |
| 通路角色 | 賣一次就結束 | **配送／安裝／維修／清潔消毒／回收一條龍** |
| 訂價 | 依給付基準 | **租金由廠商訂定、向地方政府備查，政府未統一訂價** |
| 首批 | — | 17 件產品、來自 **9 家廠商**，四大類 |

**對通路的三個結構性後果：**

1. **從「零售業」變成「服務業」。** 租賃的收入是分期的、服務是長期的、成本是回收與清消。
   這對習慣一次性買賣的輔具店，是商業模式的改變，不只是多一個品項。
2. **資本結構改變。** 租賃品要自己買進來（須檢附**購入證明**）再租出去，庫存壓在通路身上。
3. **「不用清消的品項」變得特別珍貴。** 這一點直接帶到第五節。

## 五、UTTEC 在通路結構裡的一個特殊位置（本議題最有價值的發現）

### 5.1 一個制度上的例外

- 給付清單上，**EI01–EI05 五類智慧科技輔具都標示「限租賃」**，EI05 安全看視類也在其中。
- 但《長期照顧服務申請及給付辦法》附表四之一通則有一條例外：
  > 「符合本表之功能規範品項且**涉及個人清潔衛生（購置價格低於新臺幣 5,000 元以下且無法清潔消毒使用）得以購置**。」
- 定位鞋墊貼腳、無法清潔消毒回收，落入這個例外。

**結果是：在一個「限租賃」的類別裡，它走的是購置。**

### 5.2 這對通路招募的意義（這才是重點）

把兩件事放在一起看：

| | 同類別的其他智慧輔具（限租賃） | 定位鞋墊（例外走購置） |
|---|---|---|
| 通路要不要清消場地 | **要**（每流程 5 坪、動線分離） | **不用** |
| 要不要回收物流 | 要 | 不用 |
| 要不要提營運計畫書並受審查 | 要 | **購置特約即可** |
| 庫存與資本壓力 | 高（租賃品自持） | 低（尺寸僅 S/M/L） |
| 現金回收 | 分期 | 一次 |
| 售後負擔 | 維修、更換、定期清消 | 保固與換新 |

> **一句話的通路招募論點：**
> **「在這個全部都要做租賃的類別裡，這是唯一一個你不用蓋清消間就能做的品項。」**

這句話不是行銷修辭，它是制度事實推出來的。而且它同時解釋了三件事：
- 為什麼社區藥局也能賣（不需要租賃特約的重資本門檻）
- 為什麼通路的進入成本低（不壓庫存、不建回收線）
- 為什麼通路商應該優先放這一支（毛利不用被清消與物流吃掉）

### 5.3 但有一個必須先釐清的矛盾

UTTEC 官方簡報寫「建議售價 NT$4,988（**限購置**）」，
而 1966 的給付對照表把 **EI05 安全看視類列為「限租賃」**。

兩者可以並存（因為有上述例外條款），但**對外文案必須把話講精準**，否則：
- 家屬會問：「不是說限租賃嗎？」
- 通路會問：「那我到底要不要申請租賃特約？」

> **待查證 V-6（新增）**：鞋墊在各縣市的實際給付執行方式為何？
> 是一律走購置例外，還是部分縣市仍要求走租賃？
> 這直接決定通路招募時要不要要求對方具備租賃特約資格。

## 八、我在這個議題上的判斷

1. **通路門檻提高，對 UTTEC 是好消息，不是壞消息。** 因為它的品項剛好落在門檻的另一邊。
2. **通路招募的主訴求，不該是毛利，該是「好做」。** 不用清消、不壓庫存、不用回收物流——這三句比任何分潤數字都有說服力，而且競品同類（限租賃）講不出來。
3. **對通路最有價值的交付物，是核銷文件包。** 保固書欄位齊全、序號可查、查驗字號正確——這件事廠商做一次，通路省一百次。
4. **這個議題應該優先寫成內容，而且寫給通路看，不是寫給家屬看。** 目前全網沒有人從通路視角解釋 2026 新制。
